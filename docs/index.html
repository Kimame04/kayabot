KayaBot Companion Commands & Live Channel Relay:
KayaBot runs 24/7 in the background via macOS launchd, listening for channel reflections, streaming them to Discord with circadian-coded border aesthetics, and handling personal DM commands:
/otd Multi-year flashback for today's calendar date
/stats Instant scorecard: entries, words, book pages, circadian persona
/random Surface an unexpected serendipitous memory card
/tag <name> Deep-dive into an interest tag (e.g. /tag reading)
/delete <id> Purge reflection across Telegram channel, Discord mirror & archive
/reconcile Probe recent channel posts to reconcile direct channel deletions
Quickstart Terminal Setup: 
# 1. Clone repository
git clone https://github.com/Kimame04/telegram-journal-analytics.git
cd telegram-journal-analytics

# 2. Install dependencies & configure credentials
conda env create -f environment.yml && conda activate tele-journal
cp .env.example .env

# 3. Start 24/7 background companion daemon
python -m scripts.setup_daemon install

# 4. Run full analytics suite & open master dashboard
python -m scripts.run_all --open
